# آموزگار هوشمند — بستهٔ ۲۰۰۰ سؤالی

یک اپ وب فارسی و راست‌چین، قابل نصب روی اندروید به شکل PWA، با بانک سؤال محلی، آزمون‌ساز، کارنامه، مرور اشتباهات، معلم هوشمند و جست‌وجوی تصویرهای آزاد.

## محتوای بانک سؤال

هر سؤال شناسه، درس، مبحث، سطح، چهار گزینه، شاخص پاسخ صحیح و توضیح دارد. بانک ۲۰۰۰ سؤال با شناسه‌های یکتا و متن سؤال غیرتکراری ساخته و از نظر ساختار بررسی شده است.

**محدودیت علمی مهم:** این بانک، مجموعه‌ای تألیفی و آموزشی بر پایه مفاهیم عمومی دبستان و مهارت‌های حرفه‌ای معلمی است؛ سؤال‌های رسمی آزمون استخدامی، عین سؤال‌های کتاب چهارخونه یا بانک تأییدشده وزارت آموزش‌وپرورش نیست. به‌ویژه بخشی از سؤال‌های معلمی، سناریوهای متفاوتی برای تمرین ۲۰ اصل حرفه‌ای هستند. برای استفاده جدی در آزمون، پاسخ‌ها و انطباق آن‌ها با آخرین منابع رسمی و کتاب درسی باید بازبینی شوند.

## امکانات فعلی

- بانک ۲۰۰۰ سؤالی قابل جست‌وجو و فیلتر بر اساس درس و سطح
- آزمون تصادفی ۱۰، ۲۰، ۳۰ یا ۵۰ سؤالی از بانک محلی
- آزمون پایان درس: نام مبحث را وارد می‌کنی و برنامه ابتدا سؤال‌های مرتبط را پیدا می‌کند؛ اگر سؤال مستقیم کافی نبود، از بانک همان درس آزمون می‌سازد و این محدودیت را اعلام می‌کند
- ساخت آزمون جدید با Gemini API (نیازمند کلید رایگان و سهمیه فعال)
- تصحیح خودکار، درصد، پاسخ تشریحی و نگهداری کارنامه
- ثبت درس‌های تمام‌شده و فهرست مرور اشتباهات
- معلم هوشمند با سابقه چند پیام اخیر گفت‌وگو
- جست‌وجوی تصویر در Wikimedia Commons همراه با نام پدیدآور، نوع مجوز و پیوند منبع
- واردکردن بانک JSON، خروجی بانک سؤال و خروجی سوابق
- نصب‌پذیری PWA و کش‌شدن فایل‌های اصلی و بانک برای استفاده آفلاین پس از بارگذاری اول

## فایل‌ها

- `index.html`: ساختار صفحات برنامه
- `style.css`: طراحی واکنش‌گرا و راست‌چین
- `app.js`: منطق آزمون، بانک، کارنامه، گفت‌وگو و تصاویر
- `data/questions.json`: بانک ۲۰۰۰ سؤال
- `functions/api/[[path]].js`: واسط امن سمت سرور برای Gemini
- `_routes.json`: محدودکردن اجرای Function به مسیرهای API
- `manifest.webmanifest` و `sw.js`: نصب‌پذیری و حالت آفلاین
- `assets/`: آیکون SVG و تصاویر PNG برنامه

## انتشار رایگان با GitHub + Cloudflare Pages

GitHub را برای نگهداری کد استفاده می‌کنیم و Cloudflare Pages را برای انتشار و اجرای بخش سرور. GitHub Pages به‌تنهایی این پروژه را کامل اجرا نمی‌کند، چون بخش معلم هوشمند به Function سمت سرور نیاز دارد.

1. در GitHub یک مخزن جدید بساز.
2. همه فایل‌ها و پوشه‌های داخل ZIP را مستقیماً در ریشه مخزن قرار بده؛ نه اینکه پوشه مادر را یک لایه اضافی داخل مخزن بگذاری.
3. در Cloudflare یک حساب رایگان بساز و به مسیر **Workers & Pages → Create → Pages → Connect to Git** برو.
4. مخزن GitHub را متصل کن.
5. تنظیم انتشار: Framework preset = `None`، Build command خالی، Build output directory = `.`.
6. بعد از اولین Deploy، به **Workers & Pages → پروژه → Settings → Variables and Secrets** برو.
7. یک Secret با نام دقیق `GEMINI_API_KEY` بساز و کلید Gemini را در مقدار آن قرار بده.
8. متغیر متنی اختیاری `GEMINI_MODEL` را در صورت نیاز تعیین کن؛ پیش‌فرض کد `gemini-2.5-flash-lite` است.
9. برای قفل‌کردن درخواست‌های API به دامنهٔ خودت، یک متغیر متنی `APP_ORIGIN` با آدرس دقیق سایت، مانند `https://your-project.pages.dev` ثبت کن. اسلش پایانی نگذار.
10. Deploy مجدد کن و از دامنه Pages برنامه را باز کن.

## گرفتن کلید Gemini

1. وارد Google AI Studio شو: https://aistudio.google.com/app/apikey
2. با حساب Google وارد شو و API key بساز.
3. کلید را فقط در Cloudflare به‌عنوان Secret ثبت کن؛ آن را در فایل JavaScript یا مخزن GitHub نگذار.

سهمیه رایگان Gemini به مدل، کشور، پروژه و محدودیت‌های روزانه/دقیقه‌ای وابسته است و تضمین نامحدود ندارد. در صورت پرشدن سهمیه، آزمون‌های بانک محلی و کارنامه همچنان کار می‌کنند، اما پاسخ هوشمند تا بازگشت سهمیه متوقف می‌شود.

## تصاویر

دکمه جست‌وجوی تصویر از API عمومی Wikimedia Commons استفاده می‌کند و نتیجه‌ها را همراه پیوند منبع و برچسب مجوز نمایش می‌دهد. «رایگان برای دیدن» به معنی «بدون شرط برای بازنشر» نیست؛ قبل از ذخیره یا انتشار هر تصویر، مجوز، انتساب پدیدآور و شرایط همان فایل را بررسی کن.

## امنیت و حریم خصوصی

- کلید Gemini فقط باید در Secret سمت سرور باشد.
- کد یک محدودکننده ساده درخواست و کنترل Origin دارد؛ برای انتشار عمومی یا استفاده گروهی، احراز هویت، محدودیت سهمیه به ازای کاربر و کنترل سوءاستفاده باید قوی‌تر شود.
- سوابق و درس‌های تمام‌شده فعلاً در `localStorage` همان مرورگر ذخیره می‌شوند؛ بین دستگاه‌ها همگام‌سازی نمی‌شوند.
- پرسش‌های ارسالی به Gemini از طریق API گوگل پردازش می‌شوند. در طرح رایگان ممکن است داده‌ها برای بهبود محصولات Google استفاده شوند؛ اطلاعات شخصی، محرمانه یا حساس وارد نکن.
- از ارسال اطلاعات شناسایی دانش‌آموزان، کارنامه‌ها و اطلاعات خانوادگی خودداری کن.

## محدودیت‌های نسخه فعلی

- این نسخه PWA است، نه APK بومی اندروید.
- بانک ۲۰۰۰ سؤال محلی است؛ امکان ساخت آزمون هوشمند به اینترنت و سهمیه API وابسته است.
- تکمیل درس با موضوع آزاد، ابتدا سؤال‌های مرتبط را با جست‌وجوی واژه‌ای پیدا می‌کند؛ طبقه‌بندی دقیق صفحه‌به‌صفحه کتاب چهارخونه هنوز انجام نشده است.
- ورود اطلاعات حساب کاربری، همگام‌سازی ابری، یادآور مطالعه و پنل مدیریت بانک در نسخه بعدی قابل افزودن‌اند.
- سؤال‌های تألیفی باید پیش از استفاده رسمی و جدی بازبینی شوند.
